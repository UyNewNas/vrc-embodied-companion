# Contributing

## Current phase

The project is in architecture / feasibility mode. Prefer small experiments that settle an uncertain capability.

## Rules

1. Platform claims should include a minimal reproduction or official documentation reference.
2. Do not couple world-side behavior directly to one LLM provider.
3. Any persistent user data requires a documented purpose and deletion path.
4. Companion behavior must degrade gracefully when cloud services fail.
5. Avoid engagement mechanics that exploit abandonment anxiety or exclusivity.
